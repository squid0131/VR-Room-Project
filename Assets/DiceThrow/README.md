# 投擲テスト（ダイスローダー試作）

「ダイスローダー（仮）企画書」の 1 週目の目標「掴んで投げる操作が楽しいか」を確かめるための試作です。
重さや形の違う 6 種類の道具を掴んで投げ、手応えの違いが面白いかを確認します。見た目は仮のものです。

さいころを振る機能、道具ごとの投げた後の挙動（消える・刺さる・戻る・爆発する）、敵やダメージはまだありません。

## シーンを開く

`Assets/DiceThrow/Scenes/ThrowTest.unity` を開いて Play します。

シーンはエディタースクリプトで生成しています。作り直したいときは、メニューの **Tools > Dice Throw > 投擲テストシーンを作成** を選んでください。`ThrowTest.unity` が上書きされるので、シーンに手を加えた後は注意してください。

このシーンは Build Settings に入れていないため、APK ビルドには含まれません。

## 操作

| 操作 | 入力 |
|---|---|
| 掴む・投げる | 左右どちらの手でも、グリップで掴み、腕を振りながら離す |
| 移動 | 左スティック |
| 旋回 | 右スティック |
| 道具を机に戻す | 右手 B ボタン（XR Device Simulator では R キー） |

床の外に落ちた道具（高さ -10m 以下）は自動で机に戻ります。

## シーンの構成

- **机**：プレイヤーの正面にあり、道具が並んでいます。机の前面に名前と重さが書いてあります。
- **距離目盛り**：床に 5m ごと、60m まで線とラベルがあります。
- **的**：12m 先に、崩せる箱（0.5m・2kg）のピラミッドがあります。
- **結果ボード**：正面 5m の上方に、直前の飛距離と道具ごとの最高記録を表示します。

## 道具

| 道具 | 形 | 重さ | 空気抵抗 | 特徴 |
|---|---|---|---|---|
| Stone（石） | 小さな楕円の球 | 0.4kg | 0 | 小さく速く飛ぶ |
| Apple（リンゴ） | 球 | 0.2kg | 0.15 | 一番軽く初速は速いが失速しやすい |
| Rope（ロープ） | 平たい円柱（巻いた束） | 1.0kg | 0.3 | 空気抵抗が大きく、遠くまで飛ばない |
| Spear（やり） | 長さ 1.8m の棒（机の奥） | 2.0kg | 0.02 | 投げると穂先が進行方向を向く |
| Shield（盾） | 直径 60cm の円盤 | 4.0kg | 0.1 | 一番重い |
| Bomb（爆弾） | 直径 20cm の球 | 3.0kg | 0 | 重い |

## 重さの表現

Unity の物理では、手の速さをそのまま物体に渡すと、重さに関係なく同じ速さで飛びます。そこで次の 2 つの方法で重さの違いを出しています。

1. **投げる速さ**：手の速さに次の倍率を掛けます。軽いものほど速く、重いものほど遅く飛びます。

   ```
   倍率 = Throw Power × (Reference Mass ÷ 重さ) ^ Weight Influence   （重さによる部分は 0.3〜2.0 に制限）
   ```

   初期値（Throw Power 2.0、Reference Mass 0.5kg、Weight Influence 0.35）での倍率はおおよそ次のとおりです。
   - リンゴ：約 2.8 倍
   - 石：約 2.2 倍
   - ロープ：約 1.6 倍
   - やり：約 1.2 倍
   - 爆弾：約 1.1 倍
   - 盾：約 0.97 倍

2. **持ったときの感触**：重いものほど、手の動きに遅れてついてきます。0.2kg で 20、4kg で 5 になるように、スムージング量を重さで変えています。

## 調整できる値

`Throw Test Manager` オブジェクトの Inspector で調整します。Play 中に変えてもすぐ反映されます。Play 中の変更は停止すると元に戻るので、気に入った値はメモして、停止後に入れ直してください。

| 項目 | 初期値 | 内容 |
|---|---|---|
| Throw Power | 2.0 | 投擲力の倍率。1 で手の速さそのまま。企画書の「異常な投擲力」の強さ |
| Reference Mass | 0.5 | 基準の重さ（kg）。これより軽いと速く、重いと遅く飛ぶ |
| Weight Influence | 0.35 | 重さが飛び方に与える影響（0〜1）。0 にすると重さに関係なく同じ速さ |

道具ごとの重さ・空気抵抗・穂先を向けるかどうかは、各道具の `Throwable Item` コンポーネントで変えられます。

## 飛距離の測り方

手を離した位置から、最初に何かに当たった位置までの**水平距離**を記録します。床だけでなく、机や箱に当たった場合もそこで記録されます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `Scripts/ThrowableItem.cs` | 道具 1 つ分。重さから掴み・投げの設定を決め、飛距離の計測とリセットを行う |
| `Scripts/ThrowTestManager.cs` | 全体設定（投擲力など）、結果ボードの表示、B ボタンでのリセット |
| `Editor/ThrowTestSceneBuilder.cs` | テストシーンの生成（メニュー Tools > Dice Throw） |
| `Materials/` | 仮の単色マテリアル |
| `Scenes/ThrowTest.unity` | 生成されたテストシーン |

XR リグは XR Interaction Toolkit のサンプル `XR Origin (XR Rig)` をそのまま使っています。

## 補足

- 机のラベルや結果ボードは英語です。TextMeshPro の標準フォントに日本語が含まれていないためです。
- 道具の当たり判定は、球はそのまま球、平たい円柱（ロープ・盾）は凸メッシュ、やりはカプセルと箱です。
