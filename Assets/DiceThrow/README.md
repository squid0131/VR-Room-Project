# 投擲テスト（ダイスローダー試作）

「ダイスローダー（仮）企画書」の 1 週目の目標「掴んで投げる操作が楽しいか」を確かめるための試作です。
重さや形の違う 6 種類の道具を掴んで投げ、手応えの違いが面白いかを確認します。見た目は仮のものです。

このシーンの道具には「投げた後の挙動」はありません。さいころで道具を出す機能と、投げた後の挙動（消える・刺さる・戻る・爆発する）、敵やダメージは、別シーンの「さいころテスト」（このファイルの最後）で試せます。

## シーンを開く

`Assets/DiceThrow/Scenes/ThrowTest.unity` を開いて Play します。

シーンはエディタースクリプトで生成しています。作り直したいときは、メニューの **Tools > Dice Throw > 投擲テストシーンを作成** を選んでください。`ThrowTest.unity` が上書きされるので、シーンに手を加えた後は注意してください。

このシーンは Build Settings に入れていないため、APK ビルドには含まれません。

## 操作

| 操作 | 入力 |
|---|---|
| 掴む・投げる | 左右どちらの手でも、グリップで掴み、腕を振りながら離す |
| 移動 | 左スティック |
| 旋回 | 右スティック |
| 道具を机に戻す | 右手 B ボタン（XR Device Simulator では R キー） |

床の外に落ちた道具（高さ -10m 以下）は自動で机に戻ります。

## シーンの構成

- **机**：プレイヤーの正面にあり、道具が並んでいます。机の前面に名前と重さが書いてあります。
- **距離目盛り**：床に 5m ごと、60m まで線とラベルがあります。
- **的**：12m 先に、崩せる箱（0.5m・2kg）のピラミッドがあります。
- **結果ボード**：正面 5m の上方に、直前の飛距離と道具ごとの最高記録を表示します。

## 道具

| 道具 | 形 | 重さ | 空気抵抗 | 特徴 |
|---|---|---|---|---|
| Stone（石） | 小さな楕円の球 | 0.4kg | 0 | 小さく速く飛ぶ |
| Apple（リンゴ） | 球 | 0.2kg | 0.15 | 一番軽く初速は速いが失速しやすい |
| Rope（ロープ） | 平たい円柱（巻いた束） | 1.0kg | 0.3 | 空気抵抗が大きく、遠くまで飛ばない |
| Spear（やり） | 長さ 1.8m の棒（机の奥） | 2.0kg | 0.02 | 投げると穂先が進行方向を向く |
| Shield（盾） | 直径 60cm の円盤 | 4.0kg | 0.1 | 一番重い |
| Bomb（爆弾） | 直径 20cm の球 | 3.0kg | 0 | 重い |

## 重さの表現

Unity の物理では、手の速さをそのまま物体に渡すと、重さに関係なく同じ速さで飛びます。そこで次の 2 つの方法で重さの違いを出しています。

1. **投げる速さ**：手の速さに次の倍率を掛けます。軽いものほど速く、重いものほど遅く飛びます。

   ```
   倍率 = Throw Power × (Reference Mass ÷ 重さ) ^ Weight Influence   （重さによる部分は 0.3〜2.0 に制限）
   ```

   初期値（Throw Power 2.0、Reference Mass 0.5kg、Weight Influence 0.35）での倍率はおおよそ次のとおりです。
   - リンゴ：約 2.8 倍
   - 石：約 2.2 倍
   - ロープ：約 1.6 倍
   - やり：約 1.2 倍
   - 爆弾：約 1.1 倍
   - 盾：約 0.97 倍

2. **持ったときの感触**：重いものほど、手の動きに遅れてついてきます。0.2kg で 20、4kg で 5 になるように、スムージング量を重さで変えています。

## 調整できる値

`Throw Test Manager` オブジェクトの Inspector で調整します。Play 中に変えてもすぐ反映されます。Play 中の変更は停止すると元に戻るので、気に入った値はメモして、停止後に入れ直してください。

| 項目 | 初期値 | 内容 |
|---|---|---|
| Throw Power | 2.0 | 投擲力の倍率。1 で手の速さそのまま。企画書の「異常な投擲力」の強さ |
| Reference Mass | 0.5 | 基準の重さ（kg）。これより軽いと速く、重いと遅く飛ぶ |
| Weight Influence | 0.35 | 重さが飛び方に与える影響（0〜1）。0 にすると重さに関係なく同じ速さ |

道具ごとの重さ・空気抵抗・穂先を向けるかどうかは、各道具の `Throwable Item` コンポーネントで変えられます。

## 投げる操作の補助

両方のシーンで使われます。`Throw Test Manager` の Inspector で切り替え・調整できます。

- **振った勢いで投げる**：XRI 標準の投げ方は「離した瞬間の手の動き」で飛ぶため、離すときの手首のぶれや減速で狙いが外れやすくなります。そこで、離す直前 0.12 秒で一番速かった勢いを速さに、速い瞬間ほど重く平均した向きを方向にして飛ばします。手の位置は XR リグの中の座標で測るので、スティック移動中でも振っていなければ投げたことになりません。
- **ゆっくり離すと置く**：手の速さが 1.0m/s 未満で離したときは、投擲力の倍率をかけずにそっと置きます。
- **狙いの補正**：振った向きから 10 度以内に的（敵・ロープの引っかけ場所・壊せる壁）があれば、同じ速さのまま的に届く向きに直します。道具ごとに補正先が決まっています（石・やり・盾 → 敵、爆弾 → 敵と壁、ロープ → 引っかけ場所、リンゴ → なし）。投擲テストの道具には補正先がありません。
- **道筋の表示**：振っている間（手の速さ 1.5m/s 以上）、今離したら飛ぶ道筋を線で表示します。**的に向かう道筋は緑**、それ以外は白です。投げた後は道筋が 1 秒かけて消えます。
- **軌跡**：飛んでいる道具（2m/s 以上）に白い軌跡が付きます。

| 項目 | 初期値 | 内容 |
|---|---|---|
| Use Swing Throw | オン | オフにすると XRI 標準の投げ方に戻る（比べる用） |
| Min Throw Speed | 1.0 | この手の速さ（m/s）未満で離すと置く |
| Swing Window | 0.12 | 振った勢いを測る時間（秒）。長いほど早めの振りも拾う |
| Aim Assist Angle | 10 | 狙いの補正をする角度（度）。0 で補正なし |
| Aim Assist Distance | 30 | 狙いの補正をする最大距離（m） |
| Show Trajectory / Show Trail | オン / オン | 道筋・軌跡の表示 |

## 飛距離の測り方

手を離した位置から、最初に何かに当たった位置までの**水平距離**を記録します。床だけでなく、机や箱に当たった場合もそこで記録されます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `Scripts/ThrowableItem.cs` | 道具 1 つ分。重さから掴み・投げの設定を決め、飛距離の計測とリセットを行う |
| `Scripts/ThrowTestManager.cs` | 全体設定（投擲力など）、結果ボードの表示、B ボタンでのリセット |
| `Editor/ThrowTestSceneBuilder.cs` | テストシーンの生成（メニュー Tools > Dice Throw）。道具の形もここで作る |
| `Materials/` | 仮の単色マテリアル |
| `Scenes/ThrowTest.unity` | 生成されたテストシーン |

XR リグは XR Interaction Toolkit のサンプル `XR Origin (XR Rig)` をそのまま使っています。

## 補足

- 机のラベルや結果ボードは英語です。TextMeshPro の標準フォントに日本語が含まれていないためです。
- 道具の当たり判定は、球はそのまま球、平たい円柱（ロープ・盾）は凸メッシュ、やりはカプセルと箱です。

# さいころテスト（DiceRoll シーン）

企画書の操作「左手を振るとさいころが振られ、出目の道具が現れる。右手で掴んで投げる」と、2 週目の「道具ごとの投げた後の挙動・体力・リンゴの回復・救済補正」の試作です。道具の重さ・投擲力は投擲テストと同じ `Throwable Item` / `Throw Test Manager` を使います。

## シーンを開く

メニューの **Tools > Dice Throw > さいころシーンを作成** を選ぶと、`Assets/DiceThrow/Scenes/DiceRoll.unity` と道具のプレハブ（`Assets/DiceThrow/Prefabs/Items/`）が作られます。作り直すと上書きされます。このシーンも Build Settings には入れていません。

## 操作

| 操作 | 入力 |
|---|---|
| さいころを振る | 左手を強く 3 回振る（XR Device Simulator では T キーを 3 回） |
| 道具を掴む・投げる | 右手のすぐ上に浮かぶ道具をグリップで掴み、腕を振りながら離す |
| リンゴを食べる | リンゴを持って口元に近づける |
| 移動・旋回 | 左スティック・右スティック |

### さいころ

- 振るたびに、さいころが左手の上で少し跳ねて転がります（約 7cm）。3 回目で高く放り上げられて回転し（約 24cm）、**着地すると出目が上を向き、道具が右手に現れます**。
- 出目と道具：1 石 / 2 リンゴ / 3 ロープ / 4 やり / 5 盾 / 6 爆弾。道具は前向き（やりは穂先が前）で右手の上に浮かび、掴むまで右手に付いてきます。盾は構えやすいよう、縦に立てて面を前に向けて出ます。
- **振り直すと、まだ投げていない道具（手に持っている道具も含む）は消えます。** 投げた道具は残り、場に 12 個を超えると古いものから消えます。
- **振っている途中とさいころが宙にある間は投げられません。** 手を離しても、その場に落ちるだけです。1 秒振らないと回数はリセットされます。
- 振るたびに左手が軽く振動し、着地すると両手が振動します。
- さいころの上に状態（`Shake! [##-]`、`Rolling...`、`3 : Rope`）、下に体力（`HP [#####]`）が出ます。

### 投げた後の挙動

| 出目 | 道具 | 投げた後 |
|---|---|---|
| 1 | 石 | 当たると 1 ダメージ。当たった場所の音で、近く（8m）の敵が 3 秒ほど見に来る。当たると消える |
| 2 | リンゴ | 持って口元に近づけると食べて体力 +2。投げると囮になり、12m 以内の敵はプレイヤーより優先して食べに行く（2 秒で食べ終わる）。食べられるまで残る |
| 3 | ロープ | 黄色い引っかけ場所（台の角の玉、半径 0.8m）に当たると引っかかり、台の上まで自動で引っ張り上げてくれる。引っ張り終わるか、外れて 1.5 秒たつと消える |
| 4 | やり | 3 ダメージ。穂先から勢いよく（4m/s 以上）当たると刺さったまま残り、拾い直せる。敵に刺さると一緒に動き、倒すと落ちる |
| 5 | 盾 | 構えると、その方向からの攻撃（敵のパンチ・爆発）を防ぐ。投げると水平に寝てフリスビーのように回転しながら 0.5 秒飛んで右手に戻ってくる（途中の敵に 1 ダメージ、物はすり抜ける）。手元に別の道具があると戻らずに消える |
| 6 | 爆弾 | 手を離すと導火線が点滅し、勢いよく（3m/s 以上）当たるか 3 秒で爆発。半径 3m の敵に 5 ダメージ、壊せる壁を壊し、物を吹き飛ばす。**自分も 3m 以内なら 2 ダメージ** |

### シーンの構成

- **ロープの台**：左前（x -6、z 6）の高さ 3m の台。手前右の角に引っかけ用の黄色い柱と玉がある。
- **壊せる壁**：右前（x 6、z 6）の茶色い壁。爆弾でがれきになる。
- **敵 2 体**：正面 9m 先。5m 以内に近づくか攻撃すると追いかけてきて、1.1m 以内で 1.5 秒ごとに 1 ダメージのパンチ。体力 6（頭上に `######`）。倒すと 6 秒後に元の場所で復活。床を真っすぐ歩くだけで、壁は避けません。
- **体力**：最大 5。0 になると GAME OVER と出て、2.5 秒後に開始位置で全回復して復活します（企画書の案「その部屋の最初から」は、部屋ができてから）。ダメージを受けると視界が赤く、回復すると緑に光ります。

## 調整できる値

### Dice Roller（`XR Origin (XR Rig) > Camera Offset > Left Controller > Dice Holder`）

| 項目 | 初期値 | 内容 |
|---|---|---|
| Shakes To Roll | 3 | 出目が決まるまでに振る回数（企画書では 2〜3 回） |
| Shake Speed | 1.6 | 1 回の振りと判定する手の速さ（m/s）。誤作動するなら上げる、反応しないなら下げる |
| Release Speed | 0.8 | 手の速さがこれより下がると次の振りを受け付ける（m/s） |
| Shake Timeout | 1.0 | この秒数振らないと回数がリセットされる |
| Cooldown After Roll | 0.5 | 着地した直後に振りを受け付けない秒数 |
| Right Hand | Right Controller | 道具を出す手 |
| Spawn Forward / Gap | 0.1 / 0.06 | 道具が浮かぶ位置（右手からの前方向の距離、上のすき間、m） |
| Max Items In World | 12 | 場に残す投げた道具の最大数 |
| Needed Faces / Pity Rolls | 空 / 3 | 救済補正。必要な出目が Pity Rolls 回続けて出なかったら、次は必ず出す。空なら補正なし。部屋ができたら `SetNeededFaces()` で設定する想定 |

振りの判定は、XR リグの中での手の位置の変化（トラッキング空間の位置）で測っているので、スティック移動や旋回では振ったことになりません。

### Dice Visual（Dice Holder の子の `Dice`）

| 項目 | 初期値 | 内容 |
|---|---|---|
| Hop Speed | 1.3 | 1 回振ったときに跳ねる初速（m/s）。高さは約 速さ² ÷ (2 × Gravity) |
| Toss Speed | 2.4 | 3 回目で放り上げる初速（m/s）。大きいほど道具が出るまで待つ時間も長くなる |
| Gravity | 12 | さいころにかかる重力。大きいほどきびきび落ちる |
| Toss Spin Speed / Hop Spin Speed | 900 / 400 | 宙にある間の回転の速さ（度/秒） |

### そのほか

- 道具ごとのダメージや秒数は、`Prefabs/Items/` の各プレハブの `Stone Behaviour` などで変えられます（作り直すと初期値に戻ります）。
- 敵は `Enemy` の `Simple Enemy` と `Damageable`、体力は `XR Origin (XR Rig)` の `Player Health`、ロープの引っ張りの速さは同じく `Player Rig` で調整します。
